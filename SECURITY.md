# Security Policy

## Grynvault Rebalance

Report vulnerabilities in the Grynvault packaging, release infrastructure, or
exact-channel changes privately to
[security@grynvault.com](mailto:security@grynvault.com). Do not attach wallet
databases, seeds, passwords, recovery material, macaroons, NWC connection
strings, invoices, preimages, payment secrets, private keys, complete routes,
or unredacted wallet logs.

If a report appears to affect upstream Alby Hub or LDK users, disclosure will be
coordinated privately with Alby before public discussion. The package is an
experimental independent fork and does not imply Alby endorsement.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately by emailing [security@getalby.com](mailto:security@getalby.com). Do not open a public issue or disclose the vulnerability publicly until we have coordinated a fix.

Please include the affected version or component, the potential impact, and clear steps to reproduce the issue. We will acknowledge your report and keep you informed as we investigate and address it.
